Tutorial

Getting started

Open Assets in the left menu to see every unit with its status. To move a unit, use Move Asset in the left menu or the truck icon in the list.

Your role is read only. You can look at everything, copy tags and serials, and open documents. The Move button does not appear for you.

First run, about three minutes:

  1. Click Move Asset in the left menu. You see a box for the asset tag.
  2. Type or scan a tag, or click one of the suggested tags, then Find Asset. The move form opens with the unit's details at the top. The model is a link, the copy buttons copy the tag, serial and model, and the location is a link only when it is an office.
  3. Open New status and pick Supplier Return. A panel opens asking for the exit details.
  4. Press Cancel to leave without saving. Nothing changes until you confirm.
How to

Everyday tasks

Return a unit to its supplier
  1. Open the unit with Move Asset. The move form opens.
  2. Set New status to Supplier Return. Movement type shows Check In. Location shows the supplier's address.
  3. Check the date (today by default).
  4. Attach the supplier return agreement (PDF, JPG or PNG, up to 10 MB). The file shows as a chip. Use it to open the file, replace it or remove it.
  5. Write the reason. Optionally link a replacement unit from the supplier. The Note box is optional: add a ticket number or anything that gives context.
  6. Press Move Asset, then Return to supplier in the confirmation. A "moved successfully" page counts down 5 seconds and opens the unit's Movements tab.
If something is missing, a red banner appears, the page scrolls to it and each missing field turns red with a line saying what it needs.
Record a client pulling a unit out
  1. Open the unit with Move Asset.
  2. Set New status to Client Pull-Out. Movement type shows Check Out. Location shows the client's address.
  3. Choose Why the client pulled it out: Competitor or Direct Hire.
  4. Pick the date, attach the client's instruction, and write the reason.
  5. Press Move Asset, then Confirm pull-out.
Client Pull-Out is greyed out for Monthly Rental units. Hover the option, or press its info button, to see why.
See what an exit left behind
  1. In Assets, open the status filter and pick Supplier Return or Client Pull-Out to find the units that left.
  2. Click the tag. The unit's page opens on the Activity feed.
  3. Open Movements. A Supplier Return shows as a Check In at the supplier; a Client Pull-Out as a Check Out to the client. Earlier check outs to team members stay.
  4. A document attached to the move opens in a new tab when you click it.

Why it works this way

The reasoning behind the rules

Why is there a confirmation step?

An exit is terminal. The unit leaves the active count and its history records the change and the document. The confirmation names exactly what you are about to do so a mis-click does not remove a unit by accident.

Why can't I move a unit that has already left?

A returned or pulled out unit is no longer in your custody. Its page and history stay available, but a second exit would overwrite the first and break the record. Reversing an exit is not part of this release.

Why is Client Pull-Out blocked for Monthly Rental units?

A rental unit belongs to GoTeam, not the client, so the client cannot take it. Only Outright Purchase and BYOD units can be pulled out.

Why does a document need to be attached?

The document is the proof for the exit (the supplier's agreement or the client's instruction). It stays with the movement so anyone can open it later.

Questions

Common questions

The page says "can't be moved again".

The unit was already returned or pulled out. Open its page to see the history.

The red banner says something is still needed.

Each missing field is marked red with a line under it. Fix those and press Move Asset again.

My file was rejected.

Exit documents must be PDF, JPG or PNG and up to 10 MB. Comment attachments allow images, PDF, Office files, text and zip, but not web pages (HTML or SVG).

The model or location is blue but opens only a note.

The asset model and location pages already exist elsewhere in the system. In this release the link only tells you so. A team member's address, a supplier and a client are plain text because they have no page of their own.

I pressed Confirm twice.

The exit is recorded once. A unit that has already left cannot be moved again.

What is not here

Not part of this release

  • Reversing a return or pull-out.
  • Scanning a QR code with the camera on the Move Asset page (type the tag instead).
  • Per-person permissions beyond officer and read only.
