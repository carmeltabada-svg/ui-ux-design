# Handoff Docs — Read This First

Three files here, one per audience, plus one optional data-export guide.
Nothing else in this folder needs to be read to start work.

| File | Who reads it | What it's for |
|---|---|---|
| **[DEV_HANDOFF.md](./DEV_HANDOFF.md)** | Developer | Start here. Full technical scoping, known traps, out-of-scope items, and the full-stack implementation checklist for integrating this front-end prototype into the real codebase. |
| **[QA_HANDOFF.md](./QA_HANDOFF.md)** | QA | Test cases, priority regression checks, and sign-off checklist. |
| **[HANDOFF_TICKET.md](./HANDOFF_TICKET.md)** | PM | Ticket-ready summary — paste directly into Jira/Linear/whatever you track work in. |
| **[DATA_EXPORT_GUIDE.md](./DATA_EXPORT_GUIDE.md)** | Designer (before zipping) | Optional — how to export any test data you built in the Retrieval Forms builder, since it lives only in your browser's `localStorage` and can't travel in a file-based handoff otherwise. |
